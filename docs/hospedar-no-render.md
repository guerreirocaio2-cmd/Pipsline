# Hospedar o Pipsfit no Render

O modelo padrão foi atualizado para **Render Free + Neon Free**, sem disco pago.

Siga o [guia atualizado da hospedagem gratuita](hospedagem-gratuita.md). Ele explica a criação do banco gratuito, a conexão privada no Render, o código de ativação e a instalação no iPhone.

Não use páginas antigas que ainda mostrem o plano Starter. Confira que a nova configuração apresenta **Free** antes de confirmar a criação.
